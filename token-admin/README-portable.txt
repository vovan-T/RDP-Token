RDP-Token Manager 0.7.2 — переносимая сборка для Windows x64

Запуск:
  RDP-Token-Manager.exe

Структура обязательна:
  RDP-Token-Manager.exe
  lib\...

Не переноси EXE отдельно от папки lib. В lib находятся штатные утилиты и
библиотеки для работы с Rutoken и ESMART. Драйвер токена в Windows также должен
быть установлен.

Вход администратора:
  - сервер выдаёт одноразовый запрос на 30 секунд;
  - выбранный Rutoken подписывает его внутри токена после ввода PIN;
  - PIN и закрытый ключ на сервер не передаются;
  - сервер проверяет подпись, сертификат, CRL и роль ADMIN.

Важно:
  - версия 0.7.2 требует сервер с поддержкой нового протокола;
  - форматирование полностью удаляет содержимое выбранного токена;
  - не удаляй и не переименовывай отдельные файлы в lib.

Командная диагностика без PIN:
  RDP-Token-Manager.exe --diagnose

Проверка PIN (ровно одна попытка на токен, PIN вводится в скрытом окне):
  RDP-Token-Manager.exe --test-tokens

Отчёт сохраняется в:
  %LOCALAPPDATA%\RDP-Token\reports\token-diagnostics-<дата-время>.json

PIN, закрытые ключи и полные тела сертификатов в отчёт и журнал не записываются.
